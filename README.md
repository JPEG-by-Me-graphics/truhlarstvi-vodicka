# Truhlářství Vodička mapewood

A custom website created for **Truhlářství Vodička mapewood**, a woodworking and custom furniture company.

The website presents the company's services, craftsmanship, and portfolio in a clean, modern and responsive layout.

## Live Preview

https://jpeg-by-me-graphics.github.io/truhlarstvi-vodicka/

## Technologies

* HTML5
* CSS3
* JavaScript

JavaScript is used only for selected interactive elements, while the website is primarily built with semantic HTML and custom CSS.

## Project Status

The website is currently being developed and reviewed.
Content, images and individual design elements may still change.
